# Composed agents (experiment)

Every agent in the repo's `agents/` is rebuilt here from three layers. Nothing outside this folder changes: not `agents/`, not routing, not the published modules in the repo's `skills/`.

| Layer | Where | What it holds |
|---|---|---|
| Agent | `agents/<slug>.src.md` | Who it is and how it works with the fleet: frontmatter, section order, the name (`You are **Arc**.`), one `@skill` line per layer, and its contract verbatim (Out of Scope, Handoffs, Brief Contract, Self-Validation, Output Format, Parallelism, Mandatory Pipeline) |
| Identity | `skills/ndv-neurotype-<x>/` | The mind with no name: persona, Primordial Rule, Never Does |
| Domain | `skills/ndv-domain-<x>/` | What it knows: protocols, checklists, laws, smells |

The name belongs to the agent, not the neurotype. `You are **Arc**.` sits directly above the identity `@skill` line and opens its first paragraph in the build. Inside the skill the agent is `{{name}}` (e.g. `## What {{name}} Never Does`), so another agent can reuse the same neurotype under its own name.

The skills never name another agent either: they say `{{security}}`, `{{debugging}}` and so on, and `roles.json` says which agent plays each role. None of them accepts or rejects a brief; that is the agent's job.

## Folder

```
agents/     19 agent sources + ndv-inspect (round 2 core agent, loads layers from the brief)
skills/     19 ndv-neurotype-* + 18 ndv-domain-*
roles.json  role -> agent
tools/      split_agent.py, split_all.sh, compose.mjs, build.sh, check-layers.test.js
evals/      runners (run*.mjs, judges, fleet-eval*.sh), cases-*.json, results/
build/      generated by tools/build.sh, not committed
RESULTS.md  what each round found
```

## Commands

```bash
sh tools/split_all.sh   # repo agents/ (git HEAD) -> agents/*.src.md + skills/
sh tools/build.sh       # -> build/inline (flat, like the repo's agents/), build/runtime, build/noid
node --test tools/check-layers.test.js
sh evals/fleet-eval-all.sh   # the fleet's behavior eval on the flat builds vs the originals (calls models)
```
